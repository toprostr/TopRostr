# TopRostr / Rostr — Logo kit

Final mark: **"Soft cut" TR** (Round 6 · 05, cleaned). A soft, medium-heavy TR where a smooth,
round-ended arc is cut through the letters and a ball finishes the flight.

Figma source of truth: RostrAI-1.0 → page **Brand · Logo**
(https://www.figma.com/design/5dVtSjbqhdzFlCb7MgywSB/RostrAI-1.0). Components: `Logo/Mark`,
`Logo/Lockup`, `Logo/App icon`, `Logo/Favicon`. Colours are bound to the variable collection
"Brand · Logo colors". The files here are rendered from the same vector paths.

## Colours

| Token | Hex | Use |
|---|---|---|
| logo/charcoal | `#1C1C1E` | Letters + ball on light backgrounds; app-icon tile |
| logo/off-white | `#F2F2F2` | Letters + ball on dark backgrounds; light app-icon tile |
| logo/gold | `#C99A1A` | Optional accent ball on light backgrounds |
| logo/gold-bright | `#E8B931` | Optional accent ball on dark backgrounds |
| logo/violet | `#7C6CFF` | Optional accent ball |
| logo/coral | `#FF7A59` | Optional accent ball |

Reference backgrounds: light `#F4F4F5`, dark `#14151A`.
Rules: the letters are only ever charcoal or off-white. Only the ball can take an accent, and only one accent at a time. No green.

## Typography

- Wordmark: **Manrope SemiBold (600)**, converted to outlines. The overlapping glyph contours are merged, so there are no cracks in the "t".
  - Horizontal lockup: word cap height = 72% of the TR cap height, gap = 0.42 × cap, shared baseline.
  - Stacked lockup: word cap height = 40% of the TR cap height, centred under the letters.
- Do not retype the wordmark in live text. Use the SVGs.

## Clear space & minimum size

- Clear space **x = ½ of the TR cap height** on all sides. At 1× the cap is 100 units, so x = 50.
- Minimum sizes:
  - mark: 24 px tall (below that, use the favicon)
  - horizontal lockup: 20 px tall / 110 px wide
  - stacked lockup: 48 px tall
  - favicon: 16 px

## Don'ts

Don't stretch or skew the logo. Don't recolour the letters. Don't add shadows, glows or gradients. Don't rotate it. Don't place it on busy or low-contrast backgrounds. Don't redraw the cut or move the ball.

## Files

### `svg/` (vector, tight bounds, cap height = 100 units)

- `mark-charcoal.svg`, `mark-offwhite.svg`: primary mark
- Accent-ball versions:
  - `mark-charcoal-gold-ball.svg`, `mark-offwhite-gold-ball.svg`
  - `mark-charcoal-violet-ball.svg`, `mark-offwhite-violet-ball.svg`
  - `mark-charcoal-coral-ball.svg`, `mark-offwhite-coral-ball.svg`
- Horizontal lockups:
  - `lockup-horizontal-toprostr-light-bg.svg`, `lockup-horizontal-toprostr-dark-bg.svg`
  - `lockup-horizontal-rostr-light-bg.svg`, `lockup-horizontal-rostr-dark-bg.svg`
- Stacked lockups:
  - `lockup-stacked-toprostr-light-bg.svg`, `lockup-stacked-toprostr-dark-bg.svg`
  - `lockup-stacked-rostr-light-bg.svg`, `lockup-stacked-rostr-dark-bg.svg`
- App icons:
  - `app-icon-charcoal.svg` (primary)
  - `app-icon-offwhite.svg`
  - `app-icon-charcoal-gold-ball.svg`
  - All are 1024 × 1024 with a rounded tile, rx 229. SVG can't express continuous corner smoothing.
- `favicon.svg`: simplified small-size mark on a charcoal tile, 64 × 64

`light-bg` files have charcoal artwork for light backgrounds. `dark-bg` files have off-white artwork for dark backgrounds.

### `png/`

- `app-icon-1024.png`, `app-icon-512.png`, `app-icon-180.png`: **full-bleed square** (iOS / App Store; the OS applies the corner mask). 180 = apple-touch-icon.
- `app-icon-rounded-1024.png`: rounded preview for web and marketing
- `app-icon-gold-ball-1024.png`: full-bleed version with the gold accent ball
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`

### Root

- `favicon.ico`: 16 / 32 / 48 multi-size
- `favicon.svg`: copy of `svg/favicon.svg` for `<link rel="icon" type="image/svg+xml">`

Suggested HTML:

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/app-icon-180.png">
```
